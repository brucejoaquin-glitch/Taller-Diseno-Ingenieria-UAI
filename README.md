ODS Seleccionado: 6 - Agua limpia y saneamiento


Problema a resolver: La tardanza en detectar una fuga genera una importante perdida de agua a largo plazo, lo que se traduce tambien en perdida de dinero.


Descripción del Proyecto
Detector inteligente de fugas: Sistema que utiliza un sensor de flujo conectado a un Arduino para monitorear el paso del agua. Cuando detecta un flujo continuo o anormal, el sistema activa una alerta para informar de una posible fuga y permitir una revisión rápida, reduciendo así el desperdicio de agua en la universidad.
